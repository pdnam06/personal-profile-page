# Trang web cá nhân

Trang cá nhân được xây dựng bằng HTML và CSS, gồm:

- Tiêu đề chính.
- Ảnh đại diện minh họa `avatar.svg`.
- Giới thiệu bản thân.
- Danh sách sở thích.
- Mục tiêu học tập.
- Bảng thông tin liên hệ.

Nếu muốn dùng ảnh thật, thay `avatar.svg` trong `index.html` bằng file ảnh của bạn và cập nhật thuộc tính `alt`.
